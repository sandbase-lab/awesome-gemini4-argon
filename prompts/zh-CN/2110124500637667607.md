## 提示词

```text
Build me an interactive, explorable museum of the history of programming languages, from FORTRAN (1957) to Rust.

Don't ask me for any data. Research everything yourself.

For each language, include:
Year of creation
Creator
A real, syntactically correct "Hello World" snippet
The problem the language was designed to solve

Present everything as a beautiful, zoomable, interactive timeline.

The UI should transform to match each era: punch cards, green-screen terminals, 90s Windows interfaces, and modern dark mode.

Clicking a language should display and run its Hello World in a simulated terminal.

Make the experience visually stunning, historically accurate, smooth, and fully interactive.
```
