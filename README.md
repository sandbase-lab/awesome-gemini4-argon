## Reproduce a prompt on SandBase

Gemini 4 Argon is available on SandBase as `google/gemini-4-argon`. Most entries here are **code** (HTML, SVG, Canvas, three.js) that the creator rendered and recorded, so a re-run gives you code to open in a browser, not an MP4.

1. Pick an entry marked **prompt** and copy its prompt into `prompt.txt`.
2. Create an API key in the [SandBase console](https://www.sandbase.ai/console/keys?utm_source=github&utm_medium=readme&utm_campaign=awesome-gemini4-argon) and export it as `SANDBASE_API_KEY`.
3. Call the OpenAI-compatible endpoint:

```bash
jq -n --rawfile prompt prompt.txt \
  '{model: "google/gemini-4-argon", messages: [{role: "user", content: $prompt}]}' |
curl -sS https://api.sandbase.ai/v1/chat/completions \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d @- | jq -r '.choices[0].message.content' | sed '/^```/d' > argon.html
```

Open the generated `argon.html` (Markdown fences are stripped) in a browser, or run it inside a [SandBase Sandbox](https://www.sandbase.ai/landing/sandbox?utm_source=github&utm_medium=readme&utm_campaign=awesome-gemini4-argon) to keep untrusted generated code isolated. Results vary between runs and depend on the reasoning effort; check the [model page](https://www.sandbase.ai/model/google/gemini-4-argon?utm_source=github&utm_medium=readme&utm_campaign=awesome-gemini4-argon) for current pricing and limits.
